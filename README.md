# E-book
Prevenção de golpes com inteligência artificial

Esse e-book fala sobre alguns golpes que estão se tornando mais comuns com o uso da inteligência artificial e sobre como podemos nos proteger deles.

A ideia é explicar de forma simples como esses golpes acontecem, o que devemos observar e quais cuidados podemos tomar no dia a dia para evitar problemas.
![Capa do e-book](5b47715fe99c81b0cb34ee8872156cf07fbfc89818a39a431c7176b1033ec7ec.png)
Alguns assuntos abordados:

- Vozes clonadas
- Mensagens falsas
- Imagens e vídeos manipulados
- Falsas ofertas
- Proteção de dados
- Como agir diante de um golpe
